OUR STORY WEBSITE — QUICK SETUP

Files:
- index.html
- style.css
- script.js
- photos/ (put your pictures here)

PHOTO NAMES
Put your own photos in the photos folder using these exact names:
- your-photo.jpg       (opening page, left)
- her-photo.jpg        (opening page, right)
- memory-1.jpg         (gallery)
- memory-2.jpg
- memory-3.jpg
- memory-4.jpg
- memory-5.jpg
- memory-6.jpg
- final-photo.jpg      (last page)

You can use .png or .webp too, but if you do, change the matching filename in index.html.

HOW TO RUN
1. Extract the ZIP.
2. Add your photos to the photos folder.
3. Open index.html in Chrome, or open the folder in VS Code and use Live Server.

CUSTOMIZE THE WORDS
Open index.html and edit the headings, questions, captions, and final message.
The YES/NO button actions are in script.js.
- Page 1 YES opens page 2.
- Page 1 NO shows a gentle message and stays on page 1.
- Page 2 YES opens the final page.
- Page 2 NO shows a respectful message and stays on page 2.

NOTES
- This is only HTML, CSS, and Vanilla JavaScript. No backend or framework.
- The font is loaded from Google Fonts when internet is available; fallback fonts are included.
- The photos are local files and stay on the device unless you choose to host the website.
